MY EXPENSE TRACKER — FREE PWA PACKAGE

Files:
- index.html: the app
- manifest.webmanifest: installable-app metadata
- sw.js: offline cache
- icon-192.png and icon-512.png: app icons

FREE HOSTING:
1. Upload the contents of this folder to a static HTTPS host such as GitHub Pages or Netlify.
2. Open the published HTTPS URL in Safari on your iPhone.
3. Tap Share, then Add to Home Screen.
4. Open the Home Screen icon to use the app.

PRIVACY:
Expense records are stored in browser localStorage on this device. They are not synced to a server.
Export a JSON backup regularly. Clearing browser/site data can remove records.
Keep your backup file somewhere safe.

NOTE:
This package is prepared for hosting; it has not been published to a live URL.
